##  🚀 Instrucciones de Ejecución y Uso 
**CLINICAAPP** funciona mediante una interfaz de línea de comandos (CLI). Al ejecutar el programa, verás el menú principal en tu consola.
Para interactuar con el sistema, simplemente debes escribir el número correspondiente a la opción que deseas ejecutar y presionar la tecla `Enter`.

### Opciones del Menú Principal
A continuación se explica brevemente qué hace cada opción:

####  Gestión de Personas
+ **1. Registrar paciente:** Inicia el formulario para guardar los datos de un nuevo paciente en el sistema.
+ **2. Registrar médico:** Permite dar de alta a un nuevo profesional de la salud.
+ **9. Listar pacientes:** Muestra en pantalla el registro completo de todos los pacientes inscritos.
+ **10. Listar médicos:** Muestra el listado de todos los doctores registrados en la clínica.


####  Gestión de Turnos (Citas)

+ **3. Asignar turno:** Abre el flujo para agendar una nueva cita, vinculando a un paciente con un médico.
+ **4. Listar turnos del día:** Despliega rápidamente todas las citas que están programadas para la fecha actual.
+ **5. Cancelar turno:** Permite eliminar o anular una cita previamente agendada.
+ **6. Ver turnos por médico:** Filtra la agenda para mostrar únicamente las citas asignadas a un doctor específico.
+ **7. Ver turnos por paciente:** Muestra el historial o las próximas citas de un paciente en particular.
+ **8. Cambiar estado de turno:** Permite actualizar la situación de una cita (por ejemplo: marcarla como completada, en espera, etc.).
####  Salida

+ **0. Salir:** Cierra la aplicación de manera segura y finaliza el proceso en la consola.
